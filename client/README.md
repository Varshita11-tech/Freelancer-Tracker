# Freelancer Tracker — Frontend

A premium SaaS-style dashboard for freelancers to track projects, clients, income and payments.
Frontend-only (React + Vite). All data is mocked locally — no backend required.

## Tech Stack
- React 18 + Vite
- React Router DOM
- Tailwind CSS (light/dark mode)
- Framer Motion
- React Hook Form
- Recharts
- Axios (mock service layer)
- React Icons

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173
